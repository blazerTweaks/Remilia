# REMILIA Browser — プライバシー

ステータス：**設計のみ。** このドキュメントの内容は、まだ何もビルドもテストも
されていません。各項目にはステータスがあります：`planned`（計画中）、
`implemented`（実装済み）、`verified`（テスト済みで、結果が `tests/` にある）。
現時点では、すべての項目が `planned` です。

## 原則

1. **独自コードよりもネイティブな仕組み。** Firefox にはすでに包括的 Cookie 保護、
   ETP、RFP、HTTPS-Only モード、DoH が備わっています。REMILIA はそれらを設定します。
2. **デフォルトでは LibreWolf を継承する。** `librewolf.cfg` から逸脱する場合は、
   理由を文書で残す必要があります。逸脱はすべてメンテナンスの負担になり、
   REMILIA のユーザーを、より大きな LibreWolf のユーザー集団の中で識別しやすく
   してしまう可能性があるためです。
3. **サイトを壊すなら、それに見合うプライバシー上の効果が必要。** プライバシーに
   意味のある向上をもたらさずにサイトを壊す設定は、デフォルトでは有効にしません。
4. **誇張しない。** REMILIA はトラッキングとフィンガープリンティングの攻撃面を
   減らします。誰かを匿名にするものではありません。DoH は、閲覧しているサイトを
   DoH プロバイダーから隠すものではなく、ECH を使わない限り、サイトの運営者や
   TLS の SNI を観測する者からも隠せません。

## REMILIA が保護するもの — 保護しないもの

| 保護する（軽減する） | 保護 **しない** |
|---|---|
| Cookie やストレージによるクロスサイトトラッキング | ISP やネットワークが接続先の IP アドレスを把握すること |
| 既知のトラッカーや広告のドメイン | ログイン後に、訪問先のサイトがあなたを識別すること |
| 多くの受動的なフィンガープリンティング手法 | 執念深く標的を定めた攻撃者 |
| リンクに含まれるトラッキング用クエリパラメーター | あなたのコンピューター上のマルウェア |
| ローカルネットワーク上での DNS の盗聴（DoH 有効時） | DoH プロバイダーがあなたの DNS クエリを把握すること |
| ブラウザによるテレメトリやバックグラウンドでのデータ収集 | あなたが自らウェブサイトに送信するあらゆる情報 |

## 設定のベースライン（LibreWolf の `librewolf.cfg` v8.6、Firefox 161 に基づく）

凡例 — **維持**：LibreWolf を継承する。**変更**：REMILIA が逸脱する。
**評価**：フェーズ 4 でテストを行ったうえで決定する。

### トラッキングと Cookie

| 設定 | LibreWolf | REMILIA | 備考 |
|---|---|---|---|
| `browser.contentblocking.category` | `strict` | 維持 | ETP 厳格：包括的 Cookie 保護、厳格なリスト、SmartBlock の shim、クエリパラメーターの除去。 |
| クエリパラメーター除去リスト | Brave のリスト | 維持 | `fbclid`、`gclid` などを除去する。 |
| `privacy.sanitize.sanitizeOnShutdown` | `true`（終了時に Cookie とキャッシュを消去） | **評価** | プライバシー保護は強力だが、再起動のたびにユーザーがログアウトされる。案：有効のまま、設定画面とオンボーディングでサイトごとの例外を目立たせる。 |
| ディスクキャッシュ | 無効 | 維持 | メモリのみのキャッシュ。再訪問時のパフォーマンスがやや低下する。 |
| `browser.formfill.enable` | `false` | 維持 | |
| バウンストラッキング対策 | Firefox のデフォルト | **評価** | Fx 161 の ETP 厳格モードでの状態を確認する。 |
| Global Privacy Control | 有効 | 維持 | |

### フィンガープリンティング

| 設定 | LibreWolf | REMILIA | 備考 |
|---|---|---|---|
| `privacy.resistFingerprinting` | `true` | 維持 | Tor／Mullvad／LibreWolf と共通で、ユーザーはより大きな集団に紛れ込める。副作用：タイムゾーンは UTC、ロケールは `en-US`、サイトにはライトテーマとして通知、ウィンドウサイズは丸められる。いずれも設定画面でわかりやすく切り替えられるようにする。 |
| レターボックス | 無効 | 維持 | |
| WebGL | 有効（RFP で保護） | 維持 | WebGL を無効にすると地図や 3D が動かなくなり、その選択自体がフィンガープリンティングに使われうる。 |
| WebGPU | 無効 | 維持 | |
| 独自のランダム化 | — | **行わない** | REMILIA のユーザーを小さく特徴的な集団にしてしまう。 |

うたわないこと：フィンガープリンティングに対する完全な保護。フォントの列挙、
画面サイズ、ハードウェアの詳細は RFP によって軽減されますが、なくなるわけでは
ありません。

### テレメトリとバックグラウンド接続

| 項目 | REMILIA |
|---|---|
| テレメトリ | コンパイル時に無効化（`MOZ_TELEMETRY_REPORTING` を空に設定）**し、さらに** ポリシーでも無効化。 |
| Studies／Normandy／Nimbus の実験 | 無効（`DisableFirefoxStudies`、`DisableRemoteImprovements`）。 |
| Pocket／スポンサータイル／スポンサー付きの候補／Firefox Suggest | 無効。 |
| クラッシュレポーター | **ビルドしない**（Mozilla のクラッシュサーバーはフォークのビルドを受け付けない）。クラッシュデータは一切送信されない。将来の、オプトイン式でローカルのみのクラッシュダンプ機能はロードマップ上の項目であり、機能ではない。 |
| Default browser agent | ビルドしない。 |
| AI 機能（サイドバーのチャットボット、スマートタブグループなど） | ポリシーでブロック。OpenAI のバックエンドはソースから削除（継承）。 |

引き続き想定されるネットワーク接続（フェーズ 4 でパケットキャプチャを行い、
正確に一覧化する予定）：Remote Settings（証明書の失効情報／CRLite、セキュリティ
ブロックリスト）、AMO による拡張機能のアップデート、uBO のフィルターリスト更新、
REMILIA のアップデート確認。いずれも閲覧履歴は送信しません。

### DNS とネットワーク

| 設定 | LibreWolf | REMILIA | 備考 |
|---|---|---|---|
| DoH（`network.trr.mode`） | `5`（無効） | **評価** | 無効の場合は OS のリゾルバーが使われる。有効（モード 2/3）にすると、信頼の対象がプロバイダーに移る。案：デフォルトは無効とし、初回起動時に選択肢を提示する。 |
| DoH プロバイダーのリスト | Quad9 ×2、LibreDNS ×2、Wikimedia、DNS4All | 維持 + ブラジル向けのプロバイダーの追加を評価 | 特定のプロバイダーを強制しない。 |
| DNS プリフェッチ／リンクのプリフェッチ／投機的接続 | 無効 | 維持 | |
| `network.proxy.socks_remote_dns` | `true` | 維持 | SOCKS5 プロキシを設定している場合、DNS もプロキシを経由する。 |
| WebRTC | 有効。mDNS でローカル IP を隠し、プロキシ使用時はプロキシ経由のみ | 維持 | WebRTC を無効にすると通話ができなくなり、フィンガープリンティングにも使われうる。無効化するための設定は用意する。 |
| クロスオリジンのリファラーの切り詰め | `XOriginTrimmingPolicy=2` | 維持 | |
| HTTPS-Only モード | 有効（ポリシー） | 維持 | |
| `beacon.enabled` | `false` | 維持 | |

## 検索

- デフォルトの検索プロバイダーを強制しません。提示する候補：DuckDuckGo、
  Brave Search、Startpage、Mojeek（継承）、Google、Bing。デフォルトの選択は
  今後決定します（ROADMAP の未決定事項 D1）。
- 検索候補はデフォルトで **無効** です。有効にすると、入力した文字が選択した
  プロバイダーに送信されます。設定画面にはその旨をわかりやすく明記します。
- アドレスバーは、ユーザーが確定するまでクエリをどこにも送信しません。

## REMILIA が決して収集しないデータ

REMILIA（プロジェクト）は、アナリティクスも、アカウントも、同期サービスも運営
しません。アップデート確認では、Mozilla のアップデーターの形式が必要とする
リクエスト（バージョン、ビルドターゲット、チャネル）を送信します。このリクエストに
ついては、アップデートサーバーが用意できた時点で [SECURITY.md](SECURITY.md) に
記載します。
